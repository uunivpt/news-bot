# Complete public search, library counts and official examination sources

Public search now matches headline, lead, body, source and category keywords without requiring an exact phrase. Relevance ranks an exact headline and matches to all query terms above weaker matches; English word prefixes and Unicode text are supported. Permanent news numbers are searchable. Live database queries and the archive use the same keyword rules, with identity deduplication and existing source/category/date filters and pagination. The search UI reads X-Search-Total and shows how many results have been loaded.

The homepage remains a current-feed view. Archive-only stories are not injected into it. All saved public articles remain available through search and permanent article URLs. /library/ and /api/library report deduplicated delivered article/notice totals, archive-only counts, current-feed counts and locally search-eligible counts. Private, draft and rejected records are excluded. Google-indexed totals remain explicitly unavailable: the GSC Wizard list_sites request returned payment_required/subscription_required. Sitemap eligibility is not reported as actual Google indexing, and existing quality/noindex gates are preserved.

/exams/ links to 11 explicitly configured official national and Maharashtra examination authorities. A dedicated collector reads official PDF-notice metadata, restricts every linked notice to the authority's approved HTTPS domains, excludes tenders and general navigation, and uses only an explicit date-only table cell as a publication date. It never guesses deadlines, eligibility, fees or publication dates from collection time. Notices link to their original documents; no unofficial coaching/news source is used.

Initial source collection found 186 notices from NTA, CBSE and Maharashtra CET. Other sources returned restricted/unavailable pages or no extractable PDF notice links; their status and direct official website are shown. This is coverage of the listed authorities, not a guarantee of every Indian exam. On source failure the last successful notice set and last-success time are retained without falsely marking the source fresh.

Collector/recovery schedules refresh notices through the existing hourly release gate. Historical notices are retained in the public archive and remain searchable after leaving the authority's latest-notices set. Their short source-linked notice pages remain subject to the existing noindex/ad rules. The official-source registry is visible through the existing source inventory.

Verification includes relevance, reordered words, partial words, Unicode/body/number lookup, offline archive pagination, count deduplication, official-domain restrictions, explicit-date handling and failure preservation. An isolated Chromium audit covers archived news absent from home, keyword search to the clean article URL, Maharashtra notice filters, official notice links and honest library counts. No authenticated Search Console or private production admin operation was performed.
