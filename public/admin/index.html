Security

Admin access protections currently enabled in the application.
✓ Passwords are verified against server-side password hashes.
✓ Admin session cookie is HTTP-only, Secure and SameSite=Lax.
✓ State-changing admin requests require a session CSRF token.
✓ Login failures are rate-limited per client for a short window.
✓ API responses send basic browser security headers.
✓ Secrets such as Meta tokens and database credentials are never rendered into this page.
Encryption note: traffic is protected by HTTPS in the deployed environment. This is not literal end-to-end encryption because the server must decrypt/process the authenticated admin session and database data. The design avoids exposing credentials to the browser beyond the session token.
