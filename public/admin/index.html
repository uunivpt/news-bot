Security center

Authentication and session protections.
✓ Passwords are checked server-side.
✓ Admin session cookies are HTTP-only, Secure and SameSite=Lax.
✓ State-changing requests require the session CSRF token.
✓ Failed logins are rate-limited for a short window.
✓ API responses include browser security headers.
✓ Database and Meta credentials are not rendered into the UI.

Important

HTTPS protects traffic in the deployed environment. This is not literal end-to-end encryption because the server must process authenticated requests and stored application data.
