Recovery guide

  1. Keep public reporting available

    The website can serve the most recent saved public snapshot while its database is unavailable. Snapshot age is shown above.

  2. Restore database capacity

    If Neon reports a quota limit, restore capacity in the existing database project. A deployment cannot reset a provider quota.

  3. Refresh, then authenticate again

    A recovery session stays read-only even after the database comes back. Sign out and sign in again to obtain verified owner permissions.
