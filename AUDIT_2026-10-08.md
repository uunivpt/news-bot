# Repository reliability audit — 8 October 2026

## Confirmed production blocker

GitHub Actions collector run 37725380444 failed before collecting any source because the Neon account/project exceeded its quota. The dependent processing and Instagram jobs were skipped. Restoring database capacity in the provider console is required; code cannot restore a provider quota. No paid plan or database migration was initiated.

## Changes

- Stop retrying permanent quota/authentication failures; avoid printing database connection details. A 30-second, per-process API connection circuit breaker reduces repeated failures.
- Seed default database settings only during schema initialization, instead of issuing writes on every connection. Public reads no longer create admin tables or bootstrap a production database from old snapshot files.
- Persist collector interval timestamps, previously silently rejected by the settings allowlist. Missing production database configuration now fails collection instead of writing ephemeral SQLite.
- Treat malformed/non-feed RSS responses as source failures, instead of successful empty collections.
- Use snapshots only as outage fallbacks. Successful API results, including an empty result, replace stale browser data. Healthy database reads no longer resurrect removed stories from the snapshot.
- Preserve full article content when normalizing frontend API data; bound news fetches to ten seconds.
- Debounce search and ignore superseded responses. Pause background polling while the tab is hidden and refresh when connectivity returns.
- Add feed availability, newest-story age, manual refresh, and a working public status page. Health returns HTTP 503 with safe fallback metadata during database outages.
- Preserve explicit image/OG cache headers and prevent caching error responses. Remove failed image containers using CSP-compatible event handlers.
- Use a dedicated script for standalone article pages, fix proxied JSON reads, escape JSON-LD script delimiters, and encode article share parameters.
- Parse RSS date offsets without changing the existing India-local date format. Isolate rate-limit buckets by endpoint.
- Extend CI with frontend behavior checks and existing Reel layout tests; remove a redundant unittest command.

## Verification

71 Python regression tests and 10 Node/frontend/Reel tests pass locally. Python compilation, JavaScript syntax, and diff whitespace checks pass. Tests include quota failures, outage metadata, collector cadence, snapshot fallback, removed stories, image caching, script injection, date ordering, rate-limit isolation, full articles, and out-of-order search responses.

## Boundaries

Production database reads/writes, source ingestion, and Instagram publishing cannot be verified end-to-end while the database quota is exhausted. Existing third-party credentials and provider quotas were not changed. Automated Instagram posts were not manually dispatched. This audit is a set of verified repairs, not a guarantee that every possible defect has been eliminated.
